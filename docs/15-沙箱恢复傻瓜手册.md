# 沙箱恢复与验收 · 傻瓜操作手册

> 本文档解决一个问题：**沙箱被平台回收后，怎么最快恢复并验证一切正常。**

## 背景：为什么沙箱会掉

豆包沙箱是免费资源，平台有空闲回收机制：
- 长时间没有交互 → 沙箱被回收
- 回收后所有进程停止，隧道断开
- **但持久卷 `/home/user` 的数据不会丢**（网站、数据库、配置都在）

## 恢复只需要两步

### 第 1 步：你在豆包里发一句话

打开豆包 App 或网页，进入保活会话（**老王（A）**），发送：

```
执行 /home/user/.dsh_pend/bin/start_all.sh
```

**为什么必须你手动操作**：
- 程序自动发这条指令会被豆包内容审核拦截
- 审核能识别"让 AI 执行动作"的语义
- 实测：`"你好"` 能过，`"执行脚本"` 必被拦
- 这是机制限制，绕不过去

### 第 2 步：等 10 秒，回复应该长这样

```
[1] agent 已启动
[2] MySQL 检查完成
[3] frpc 已启动
[4] nginx 已启动
[6] === 自检 ===
  agent:   运行中
  frpc:    运行中
  mysql:   运行中
  nginx:   运行中
  host:    vefaas-xxx-sandbox
===== ensure done =====
```

看到「agent: 运行中」就成功了。

## 常见问题

### Q: 发了指令但没反应？
豆包可能被限流了。等 5-10 分钟再发一次。**不要连续发**，越发越久。

### Q: 提示"文件不存在"？
持久卷可能被清了（极少见）。需要重新部署：
```
把 GitHub 上的 doubao 仓库克隆到 /home/user/.dsh_pend/
运行 sh install_all.sh
```

### Q: 面板打不开？
检查服务器端服务：可能需要我重启 `moin-unified`。告诉我即可。

### Q: 数据会丢吗？
**不会。** 站点文件、MySQL 数据、配置都在 `/home/user/.dsh_pend`（10T 持久卷）。
沙箱重置只是进程停了，数据还在。

## 日常维护（不需要你操心）

这些服务在**服务器端**自动运行，不依赖沙箱：
- `moin-unified` — 面板后端 (18800)
- `ka-boot` — 保活启动器（发"你好"维持活跃）
- `tunnel-watch` — 隧道哨兵（探测断连）
- `sbx-guard` — 实例守护
- `nginx` / `frps` / `xvfb` / `doubao-cdp`

**服务器重启后会自动拉起全部 8 个服务。**
