# 给豆包/AI 助手的部署指令（直接复制）

> 本文档是给**豆包助手**看的。用户把这段贴给豆包即可。

## 首次部署

```
帮我部署 Moin 面板。请依次执行（每步执行完把输出发我，不要跳过）：

1. cd /home/user/.dsh_pend && git clone --depth 1 https://github.com/Orengr/doubao.git moin-deploy
2. cd moin-deploy && sh install_all.sh
3. 执行完后运行：curl -s "http://127.0.0.1:17802/api/ping?token=$(cat /home/user/.dsh_pend/state/token.txt)"
4. 把上面命令的输出原样发我

注意：install_all.sh 会自动装 MySQL/PHP/依赖，可能需要几分钟，请耐心等待，不要中断。
如果中途报错，把最后的错误信息发我，不要重复执行。
```

## 沙箱被重置后

```
沙箱刚被重置了，请执行：
sh /home/user/.dsh_pend/bin/start_all.sh
然后把输出发我。
```

## 检查面板状态

```
请执行并原样返回输出：
curl -s "http://127.0.0.1:17802/api/overview?token=$(cat /home/user/.dsh_pend/state/token.txt)"
```

## 建一个网站

```
请执行：
curl -s -X POST "http://127.0.0.1:17802/api/site_create?token=$(cat /home/user/.dsh_pend/state/token.txt)" -H "Content-Type: application/json" -d '{"name":"mysite"}'
然后把输出发我，并告诉我网站目录在哪。
```

## 重要：避免额度不足

如果任务超过 1 分钟：

```
请在后台执行（不要在前台等）：
cd /home/user/.dsh_pend && setsid nohup sh 你的脚本.sh > /tmp/task.log 2>&1 < /dev/null &
然后告诉我"已在后台启动"，过一会我再问你要 /tmp/task.log 的内容。
```

## 遇到平台拦截

如果出现「检测到高风险行为，已终止会话」：
1. 不要重试整条命令
2. 拆成单条命令，一条一条发
3. 或者让用户从服务器侧用控制面接口执行（见 docs/09-额度与执行通道.md）
