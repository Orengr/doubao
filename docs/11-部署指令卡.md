# 豆包部署指令卡（直接复制粘贴）

> 复制下面整段发给豆包，它会自己读文档部署。

---

```
请帮我部署 Moin 面板服务器。按以下步骤执行，每步做完把输出发我：

【规则】
1. 不要一次跑长命令，超过 1 分钟的任务必须后台跑：
   setsid nohup sh 脚本.sh > /tmp/x.log 2>&1 < /dev/null &
2. 装完后过 2 分钟再 tail -30 /tmp/x.log 看结果
3. 如果提示"高风险行为已终止会话"，不要重试，拆成单条命令
4. 不要重复执行同一个安装脚本

【第1步 拉代码】
cd /home/user/.dsh_pend && git clone --depth 1 https://github.com/Orengr/doubao.git moin-deploy

【第2步 检查预编译包】
ls -lh /home/user/.dsh_pend/pkg/
如果没有 mysql-8.0.40-linux-glibc2.17-x86_64.tar.xz 和 php81-prebuilt.tar.xz，
从 https://github.com/Orengr/doubao-bt-deploy/releases 下载放到该目录。

【第3步 后台安装】
cd /home/user/.dsh_pend/moin-deploy
setsid nohup sh install_all.sh > /tmp/install.log 2>&1 < /dev/null &
然后告诉我"已启动，等2分钟"

【第4步 检查结果（2分钟后）】
tail -30 /tmp/install.log
看到"部署完成"且 MySQL/PHP/Agent 都 OK 就成功

【第5步 报给我】
把面板地址、MySQL/PHP 版本、装好的功能列表用大白话告诉我
```

```

执行：
curl -s -X POST "http://127.0.0.1:17802/api/site_create?token=$(cat /home/user/.dsh_pend/state/token.txt)" -H "Content-Type: application/json" -d '{"name":"mysite"}'
然后把输出和网站目录路径告诉我。
```

## 额度不够时

如果对话提示额度不足或任务中断：
- 不要把整个部署脚本重跑一遍
- 改成一步一步来：先拉代码 → 再检查包 → 再后台安装 → 再查日志
- 或让用户从服务器侧用控制面接口执行（见 docs/09-额度与执行通道.md）
