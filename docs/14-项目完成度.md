### 修复：SSE 转义导致解析失败
豆包返回的 SSE 是双层转义：
```
data: {"event_data":"{\\"message_id\\":\\"62017163755567106\\"}"}
```
原来的正则 `r'"message_id":"(\d+)"'` 匹配不到。

**修正为宽松正则**：
```python
mid  = re.search(r'message_id[^0-9]{1,10}(\d{10,})', raw)
conv = re.search(r'conversation_id[^0-9]{1,10}(\d{10,})', raw)
```
