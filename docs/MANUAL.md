# 第 0 部分 · 先搞懂 3 个问题

## 这个东西是什么？

它能让你的**豆包 AI 助手**变成一台**24 小时在线的小服务器**。
在这台服务器上，你可以：
- 搭自己的个人网站
- 存文件
- 学习 Linux 和服务器运维

## 需要花多少钱？

**0 元。** 所有组件都是免费的。

## 需要准备什么？（一共 4 样，下面会一步步教）

| # | 东西 | 说明 | 大概耗时 |
|---|---|---|---|
| ① | 一台有公网 IP 的小电脑 | 叫「中转机」，是你自己的 | 注册 VPS 约 5 分钟 |
| ② | 一个豆包账号 | 你手机里装的那个豆包 App 的账号 | 已经有了 |
| ③ | 扫一次码 | 让系统认出你的账号 | 30 秒 |
| ④ | （可选）一个域名 | 想用好记的网址才需要 | 10 分钟 |

**明确不需要的：**
- ❌ 不需要花钱买面板
- ❌ 不需要域名备案
- ❌ 不需要信用卡
- ❌ 不需要会写代码

# 第 1 部分 · 准备中转机（第①样）

## 1.1 什么是「中转机」？

一台 24 小时开着的小电脑。它的作用像「传达室」：
别人访问你的网址 → 先到传达室 → 传达室把请求转给你在豆包里的真正服务器。

**这台机器是你自己的，跟本项目作者没有任何关系。**

## 1.2 怎么弄一台？

任选一种（都是注册账号 → 创建机器 → 拿到 IP）：

**方式 A：你已有的 VPS**（如果你本来就有一台）

- 确认是 Linux（Ubuntu 22.04 / Debian 12 / CentOS 8+ 都行）
- 最低配置：1 核 CPU / 512MB 内存 / 5GB 硬盘

**方式 B：Oracle 云免费机**（永久免费，但注册要看运气）

1. 打开 https://www.oracle.com/cloud/free/
2. 点 Start for free，注册账号（要信用卡验证但不会扣钱）
3. 创建实例时选「Always Free」的机器
4. 记下分配的公网 IP

**方式 C：fly.io 免费额度**（注册简单）

1. 打开 https://fly.io
2. 注册 → 安装 flyctl → `fly launch`
3. 具体方法网上搜「fly.io 免费容器 教程」

**方式 D：任何你能弄到的免费服务器**

## 1.3 拿到机器后，必须做的 3 件事

**① 确认能登录**

用 SSH 工具登录你的机器（Windows 用 Termius/PuTTY，Mac 直接开终端）：

```
ssh root@你的机器IP
```

输入密码后看到欢迎信息就是成功。

**② 查看你的公网 IP（记下来！）**

登录后输入：

```
curl https://api.ipify.org
```

屏幕会显示一串数字，比如 `1.2.3.4`。**这就是你的中转机 IP，抄下来。**

**③ 开放端口（很重要，不做后面全打不开）**

在你的云服务商控制台里（阿里云叫「安全组」，Oracle 叫「安全列表」），
添加规则，放行下面这些端口：

| 端口 | 用途 | 必须开吗 |
|---|---|---|
| **22** | SSH 登录 | 必须（一般默认已开） |
| **80** | 网页入口 | 必须 |
| **7000** | frp 通道（沙箱连回来用） | 必须 |
| **18800** | 管理台（扫码登录用） | 必须 |
| **17800** | 沙箱直连（可选） | 建议开 |
| **18090** | 1Panel 直连（可选） | 建议开 |

添加方法（以阿里云为例）：
```
控制台 → 你的实例 → 安全组 → 配置规则 → 入方向 → 手动添加
端口范围填一个，授权对象填 0.0.0.0/0，保存。
一个端口加一条，上面表格里「必须」的都要加。
```

✅ 检查方法：加完后，在你自己的电脑浏览器输入 `http://你的中转机IP`
   如果显示「无法访问」或者页面空白，都算正常（因为还没部署），
   只要不是「连接被拒绝」就行。

# 第 2 部分 · 部署中转机（第②步，1 条命令）

## 2.1 把项目文件弄到中转机上

**方式 A：git clone（推荐，一条命令）**

登录中转机后输入：

```
git clone https://github.com/Orengr/doubao.git
cd doubao
```

看到 `done.` 或者进度条走完就是成功。

**方式 B：手动下载（不会用 git 的话）**

在中转机输入：

```
curl -fsSL -o doubao.tar.gz https://github.com/Orengr/doubao/archive/refs/heads/main.tar.gz
tar xzf doubao.tar.gz
cd doubao-main
```

## 2.2 填写你的信息（一份小表格）

把配置模板复制一份：

```
cp config.env.example config.env
```

然后用编辑器打开它（nano 是最简单的）：

```
nano config.env
```

你会看到这样的内容，**只需要改 1 个地方**：

```
# 必填：你自己的中转机公网 IP
FRPS_ADDR=          ← 在等号后面填你第 1.3 步抄下来的 IP，比如 FRPS_ADDR=1.2.3.4

# 可选：域名（没有就保持空白）
DOMAIN=

# 其他保持默认
```

改完后：
- 按 `Ctrl + O` 保存
- 按 `Enter` 确认
- 按 `Ctrl + X` 退出

✅ 检查：输入 `cat config.env`，能看到你填的 IP 就是成功。

## 2.3 一键安装

输入：

```
bash install.sh
```

然后**等它跑完**（1～2 分钟）。屏幕会滚很多字，最后你会看到：

```
================================================
  部署完成！
================================================
【中转机信息】
  frps 地址:  1.2.3.4:7000
  frp token:  一串字母数字
  访问入口:   http://1.2.3.4/
  1Panel:     http://1.2.3.4/panel/
【下一步】
  1. 打开豆包，新建会话，切换到【云电脑】模式
  2. 把 /root/SANDBOX_CMDS.txt 里的内容发给它
  ...
```

✅ **看到「部署完成！」就是成功。**

**这步做了什么（看不懂没关系）**：
装了 3 个东西：frps（传达室大门）、nginx（引导员）、管理台（你的控制面板）。

# 第 3 部分 · 部署豆包沙箱（第②样，让豆包干活）

## 3.1 打开豆包，新建会话

1. 手机或电脑打开豆包（App 或 https://www.doubao.com 都行）
2. 点「新对话」
3. **必须切换到「云电脑」模式！**

   怎么切：在输入框附近找到「对话」两个字旁边的箭头 ›，
   点开菜单，选「工作任务 · 云电脑」。

   ⚠️ **不切的话豆包只会跟你聊天，不会真的帮你干活！**

## 3.2 把部署指令发给豆包

中转机上有个文件存着要发给豆包的话。查看它：

```
cat /root/SANDBOX_CMDS.txt
```

屏幕会显示一大段文字。**全选复制**它。

回到豆包对话，粘贴，发送。

## 3.3 等豆包干活

豆包会自己下载、解压、启动（大约 1～3 分钟）。

✅ **看到「===== 部署完成 =====」和一堆文件列表就是成功。**

如果豆包说「我不能执行」，检查：
- 是不是真的切到云电脑模式了？
- 有没有把整段话发全？

# 第 4 部分 · 扫码登录（第③步，30 秒）

## 4.1 打开管理台

在你**自己的电脑或手机浏览器**输入：

```
http://你的中转机IP:18800/
```

比如 `http://1.2.3.4:18800/`

## 4.2 进入扫码页面

1. 点左上角 **≡**（三条横线的按钮）
2. 点「扫码登录」
3. 点「获取二维码 / 重新登录」按钮

页面上会出现一个带豆包图标的二维码。

## 4.3 用豆包 App 扫码

1. 打开手机上的**豆包 App**
2. 点右上角 **+** 或扫一扫功能
3. 对着电脑屏幕上的二维码扫
4. 手机会弹出「确认登录」→ **点确认**

## 4.4 看到成功

回到 18800 页面，等几秒，会变成：

```
✓ 已登录（35 个 cookie）· 浏览器常驻，自动续期
```

✅ **看到这个就是成功。** 这一页先别关。

# 第 5 部分 · 系统自动干活（你不用动）

扫码成功后，系统会**自动**：

1. 保存你的登录信息
2. 解除保活熔断
3. 通过豆包拉起沙箱里的服务
4. 恢复保活循环（每 2~2.5 分钟做一个小任务保持活跃）

你什么都不用做，等 1~2 分钟即可。

# 第 7 部分 · （可选）配置域名

**没有域名完全可以正常用**（用 IP 访问）。想要好看的网址才做这步。

1. 在域名商（阿里云/腾讯云/Cloudflare 等）买个域名
2. 到域名管理后台，添加一条 **A 记录**：
   - 主机记录：`@` 或 `panel`（随便起）
   - 记录值：你的中转机 IP
3. 等 5~10 分钟生效
4. 浏览器用域名访问试试

⚠️ 注意：**国内服务器（阿里云/腾讯云大陆区）域名必须备案**，
不备案会被拦截。解决方案：
- 用境外服务器（不用备案）
- 或直接用 IP 访问

# 第 8 部分 · 日常使用与维护

## 8.1 日常要做什么？

**什么都不用做。** 系统自动保活、自动续期、自动恢复。

## 8.2 打不开了怎么办？

按顺序检查：

```
第1步：打开 http://中转机IP:18800/ 能打开吗？
  ↓ 能打开，显示已登录 → 看 18800 页面的系统自检区块
  ↓ 打不开 → 中转机挂了，去云服务商控制台重启机器

第2步：18800 显示「需要扫码」→ 重新扫一次码（第 4 部分流程）

第3步：系统自检里有 ✗ → 看是哪个组件
  → 在豆包对话里发：「帮我运行 sh /home/user/.dsh_pend/bin/ensure.sh」

第4步：还不行 → 查看状态总览
  在中转机输入：bash bin/status.sh
  把输出发给豆包，让它帮你排查
```

## 8.3 状态总览命令（一键看全系统）

在中转机输入：

```
bash bin/status.sh
```

会显示所有服务、端口、登录状态、隧道、最近日志。

## 8.4 自测命令（确认 88 项功能正常）

```
bash test.sh
```

## 8.5 密码忘了？

1Panel 密码：在豆包对话发「帮我执行 1pctl update password 修改密码」
管理台：不需要密码（只有本机能访问）

## 8.6 想改保活频率？

编辑中转机 `/root/keepconf.json` 或在 18800 管理台「保活控制」页调整。

# 第 9 部分 · 常见问题（大白话）

**Q1：豆包沙箱是什么？会一直免费吗？**
A：豆包的云电脑功能。是否收费由字节决定，本项目无法保证。

**Q2：为什么部署完过几个小时就打不开了？**
A：沙箱被平台回收了（正常现象）。系统会自动恢复；如果没恢复，
   在豆包对话里重新发 ensure.sh 指令即可。

**Q3：为什么要扫码？不扫行吗？**
A：豆包服务端要求登录。不扫就没法用。扫一次后系统会自动续期。

**Q4：数据会丢吗？**
A：存在 10T 持久卷的数据不会丢（沙箱重建也在）。但装在系统目录的
   东西会丢，所以本项目所有东西都放持久卷。

**Q5：能跑游戏/挖矿/代理吗？**
A：不要。违反豆包服务条款，会被封号。

**Q6：我的 IP 是固定的吗？**
A：沙箱的出口 IP 每次重建会变。中转机 IP 固定。

**Q7：别人能访问我的服务器吗？**
A：只有知道你中转机 IP 的人能访问入口页。1Panel 有密码。
   建议部署完立刻改 1Panel 密码。

**Q8： 怎么彻底删除这套东西？**
A：中转机：`rm -rf /root/dbp-release /root/frps.toml` 并停服务；
   沙箱：删除 /home/user/.dsh_pend/ 目录即可。
