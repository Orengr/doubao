# Moin 面板使用手册

## 访问

| 入口 | 地址 | 说明 |
|---|---|---|
| 面板 | `http://<服务器IP>/panel` | 14 个功能页 |
| 管理台 | `http://<服务器IP>/lite/` | 登录/保活/会话管理 |
| 导航页 | `http://<服务器IP>/` | 总入口 |
| 文件下载 | `http://<服务器IP>/dl/` | 部署包/文档 |

全部走 **80 端口**，手机浏览器直接可用。

## 面板功能（14 项）

### 监控分组
| 页面 | 功能 |
|---|---|
| **概览** | CPU/内存/磁盘环形图、负载、进程数、运行时长，**3 秒实时刷新** |
| **服务健康** | 6 项探测（控制面/Agent/frpc/nginx/MySQL/PHP） |
| **PHP 环境** | PHP 版本号 + 已加载模块列表 |
| **豆包会话** | 会话列表 + 消息数 + 存活状态 + 保活标记（**沙箱离线也能看**） |

### 运维分组
| 页面 | 功能 |
|---|---|
| **文件管理** | 浏览持久卷目录、查看文件内容 |
| **磁盘占用** | 各目录占用排行 + 进度条 |
| **计划任务** | cron 添加与列表 |
| **进程** | Top 40 进程（CPU/内存排序） |
| **容器应用** | proot 隔离运行 + 启动表单 |
| **备份** | mysqldump + tar.gz 打包 |
| **终端** | 沙箱内执行任意命令 |

### 建站分组
| 页面 | 功能 |
|---|---|
| **网站** | 新建站点 / **绑定域名** / **开 SSL** / **反向代理** / **查看日志** / 删除 |
| **数据库** | MySQL 库列表、建库、查表 |
| **FTP 账户** | SFTP 说明 |

## 建站完整流程

### 1. 新建站点
面板 → 网站 → 输入站点名（如 `blog`）→ 创建站点

自动完成：
- 建目录 `/home/user/.dsh_pend/www/blog`
- 生成 `index.html`
- 写 nginx 配置到 `conf/sites/blog.conf`

### 2. 绑定域名
网站列表 → 点「绑定域名」→ 输入 `blog.example.com`

效果：修改 nginx 配置的 `server_name`，支持多域名追加。

### 3. 开启 SSL
网站列表 → 点「开 SSL」

自动用 openssl 生成自签证书（3650 天），nginx 监听 8443。

### 4. 反向代理
网站列表 → 点「反代」→ 输入后端地址（如 `http://127.0.0.1:8080`）

把站点流量转发到指定后端服务。

### 5. 查看日志
网站列表 → 点「日志」→ 显示最近 60 行 nginx 日志。

### 6. 数据库
数据库 → 输入库名 → 创建 → 点「查看表」看该库的表。

## 实时刷新说明

**概览页每 3 秒自动更新**，无需手动刷新：
- 内存/磁盘环形图
- 负载数值
- 进程数
- 运行时长
- 更新时间戳

健康页和进程页同样 3 秒刷新。

## 沙箱离线时的表现

如果沙箱被平台回收，所有页面会显示：
```
沙箱未连接：agent: Connection refused（实例可能正在重建，约20秒后自动恢复）
```

**不会白屏、不会崩溃。** `sbx_guard` 守护会在检测到实例重建后自动恢复。

## 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 页面显示"沙箱未连接" | 沙箱被回收 | 等 20-30 秒自动恢复，或发消息唤醒 |
| 发送消息失败 | 豆包限流 | 等 5-30 分钟，不要连续重试 |
| MySQL 连不上 | 服务未启动 | 终端执行 `sh bin/start_mysql.sh` |
| 站点打不开 | nginx 未重载 | 网站页操作后会自动 reload，或终端 `nginx -s reload` |

## 保活节奏（重要）

保活**模拟真人使用习惯**，不是机器刷屏：

| 参数 | 值 |
|---|---|
| 活跃时段 | 9:00-23:00 |
| 每次会话 | 2-5 条 |
| 条间隔 | **90-180 秒** |
| 会话间隔 | 25-50 分钟 |
| 每日上限 | 60 条 |
| 深夜 | 90-150 分钟一条 |

**为什么这么设计**：实测发现间隔太短（<20 秒）必被限流，而且发得越多冷却越长。一天几百条没问题，但如果 30 秒一条不停发，账号会被标记。
